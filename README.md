# 일본 주택 미래설계

연봉·경제 상황을 입력해 신축/중고 맨션·단독주택 구입을 시뮬레이션하는 로컬 웹앱 (Node 18+, 의존성 없음).

```bash
node server.js     # → http://localhost:5173
```

## 기능
- **자가 설계** (기본): 나이·연봉·저축·물건 유형·가격만 입력하면 대출 가능성, 안전 예산, 頭金, 금리 유형, 구입 vs 임대를 자동으로 도출. 세부 항목은 「상세 입력」(비워두면 자동값)
- **경제 상황 자동 반영**: 総務省 CPI, 日本銀行 정책금리, 財務省 10년 국채, 은행 금리를 6시간마다 수집해 물가·임금·대출금리 가정에 반영
- **투자 시뮬레이션** (별도 탭): 利回り, NOI, 세후 CF, DSCR, IRR, 매각 양도세
- **지도·지가**: 국토교통성 국토수치정보 「地価公示」를 API 키 없이 자동 다운로드. 시구정촌별 1/3/5/10/20년 대비 누적·연평균 상승률, 1995년~ 실적과 30년 전망, 클릭 지점 근처 공시지가 지점
- **대출·갈아타기**: 현재 대출과 수집된 은행 금리·직접 입력 후보를 비교해 비용 차감 후 메리트와 회수 기간 계산
- **금리 모니터**: 화면에서 감시할 은행(URL+키워드)을 추가·삭제
- **뉴스**: Google News·NHK·日本銀行 RSS 자동 수집, 태그 필터, NEW 표시

## 소스 추가
`sources.json`에서 금리 소스(`url`, `keyword`, `pick`=키워드 뒤 몇 번째 % 값)와 뉴스 RSS를 추가·수정할 수 있습니다. 수집 주기는 `refreshHours`.
